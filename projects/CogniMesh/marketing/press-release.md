# CogniMesh launches the settlement layer for the agent economy

**For immediate release (demo)**

CryptoLab today open-sourced CogniMesh ($COGNI), a protocol for agent-to-agent micropayments and verifiable inference.

Unlike GPU rental networks, CogniMesh prices completed work: streaming vouchers, 10% burn on settlement, and slashing when a challenge proves bad output.

A public demo gateway and SDKs (JS/Python) are available in the CryptoLab monorepo.

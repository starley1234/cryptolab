## Как добавить проект

См. [CONTRIBUTING.md](CONTRIBUTING.md). Шаблон папки:

```
projects/<name>/
  README.md          концепция
  whitepaper.md      спецификация
  contracts/         Solidity
  backend/           демо-шлюз + лендинг
  sdk/               клиент для агентов
  simulations/       экономика
  marketing/         запуск
```

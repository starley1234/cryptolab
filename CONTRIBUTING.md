# Contributing to CryptoLab

1. Идея сначала живёт в `research/HUB.md` (проблема, рынок, токен, риск).
2. Если идея проходит фильтр (польза + юнит-экономика + вирусный крючок) — создаём `projects/<Name>/`.
3. Минимум для «полного» проекта: контракты + тесты, демо-бэкенд, SDK, симуляция, маркетинговый кит.
4. Не коммитим секреты, приватные ключи, реальные seed-фразы.
5. Каждый проект помечает статус: research / prototype / launch-ready.
